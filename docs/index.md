# Welcome

This is your central documentation site powered by [ai-multisync-tool](https://github.com/your-org/ai-multisync-tool).

Documentation for your services will appear here automatically once you configure the sync pipeline.

## Getting started

Follow the setup guide in the [README](https://github.com/your-org/ai-multisync-tool#readme) to:

1. Configure this Docusaurus site
2. Add the central workflow to this repository
3. Add the source workflow to each service repository

## Structure

Once services are connected, their documentation will be synced into `docs/services/<service-name>/`.
